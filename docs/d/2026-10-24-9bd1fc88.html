조건이 복잡해 보여도 핵심만 보면 금방 판단할 수 있어요. 누가 받는지, 얼마인지, 어떻게 신청하는지 순서로 정리했어요.

얼마나 지원되나요?

○ 서비스 개요: 종로사랑상품권 할인 판매

○ 사업 목적 : 소상공인의 결제수수료 부담 경감 및 지역경제 활성화 유도

○ 지원내용 : 서울Pay+ 앱을 통한 종로사랑상품권 모바일 발행

○ 사용혜택
- 가맹점 : 모바일 상품권 결제 시 수수료 0%
- 소비자 : 상품권 구매 시 5% 할인, 소득공제 30%

○ 사용방법 : QR코드를 활용한 모바일 간편결제(소비자계좌→가맹점 계좌)

○ 구매기간 : 매년 설·추석 명절 2주 전~판매완료 시까지

○ 구매금액 : 1~50만원 단위까지 만원 단위로 모바일 충전

○ 구매한도 : 1인당 월 50만원

○ 보유한도 : 150만원
※ 선물받기 한도 : 월 150만원(동일 상품권에 대해 적용)

○ 환불기준
- 구매취소 : 기간에 관계없이 전액 취소 가능
- 잔액환불 : 액면가 60% 이상 사용 시 할인지원금 제외 후 환불

○ 사 용 처 : 종로사랑상품권 가맹점 22,090개소(2026.9.7. 기준)
※ 대형마트, 백화점 등 일부 대형가맹점, 유흥 사치업 제외

○ 유효기간 : 발행일로부터 5년

○ 문 의 처
- 일반 문의 : 서울페이플러스 콜센터(☎1600-6120)
- 상품권 발행시기 및 할인율 : 종로구 일자리정책과(☎02-2148-2322)

소득 기준이 있나요?

네, 있습니다. 공고에는 "소비자 : 상품권 구매 시 5% 할인, 소득공제 30%"로 안내되어 있어요. 본인 소득이 기준 안에 드는지 먼저 확인하세요.

다른 지역에 살아도 신청할 수 있나요?

이 지원은 서울특별시 종로구에서 운영하는 것이라 기본적으로 해당 지역 거주자(주민등록 기준)가 대상입니다. 다른 지역은 거주지 지자체의 유사 지원을 확인하세요. 아래 '지역별·유사 지원' 표도 참고하세요.

언제까지 신청해야 하나요?

신청 기한은 "접수기관 별 상이"입니다. 예산이 소진되면 조기 마감되는 경우가 많으니 되도록 빨리 신청하세요.

아래는 정부 지원금·금리·청약 안내 블로그 초안이야. 이걸 사람이 직접 쓴 것처럼 자연스럽게 다듬고, 운영자의 생각이 담긴 문단을 추가해줘.

[운영자 설정]
경남 창원에 사는 30대 직장인. 지원금·금리·청약 정보를 직접 찾아보고 정리하는 블로그를 운영 중. 말투는 존댓말, 친근하지만 가볍지 않게.

[지켜야 할 것]
1. 금액, 대상 조건, 기한, 기관명, 링크는 절대 바꾸거나 새로 지어내지 마. 원문에 없는 정보가 필요하면 "공고 확인 필요"라고 써.
2. h2, h3, 표, 링크 같은 HTML 구조는 그대로 유지해. 출력은 HTML만, 설명이나 코드 표시 없이.
3. 공고문 말투를 옆집 아는 사람이 설명해 주듯 풀어 써. 조건을 뭉뚱그리지 말고 숫자는 정확히 남겨.
4. 서두 두 문단은 통째로 새로 써. 이 지원이 왜 쓸만한지, 어떤 사람한테 특히 좋은지로 시작해.
5. 운영자 생각 문단을 2곳 추가해. 위치는 본문 중간(지원 내용이나 표 다음)과 신청 방법 다음. 각 2~4문장. 내용은 이런 것들로:
   - 조건을 보고 느낀 점 (예: "소득 기준이 생각보다 넉넉해서 맞벌이도 해볼 만합니다")
   - 신청할 때 헷갈릴 만한 부분과 그 이유
   - 비슷한 지원과 비교했을 때의 장단점
   - 어떤 사람은 서두르고 어떤 사람은 안 해도 되는지
   단, "제가 신청해 봤더니", "제 주변 사람이 받았는데" 같은 직접 경험담은 쓰지 마. 정보를 읽고 판단한 의견만 써.
6. "무조건", "100%", "꼭 받으세요" 같은 과장은 쓰지 마.
7. 이모지는 한두 개 이하. 글 전체 길이는 원문의 1.2배 이내.

[초안]
<p><strong>지역화폐(종로사랑상품권)</strong>, 정리해 봤습니다.</p>
